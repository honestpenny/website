# Fact-check: Care-First renewal checker, phone fee letter, insurance guide rate-caps section (2026-11-25)

Independent check. Every source below was re-read live on 2026-11-25, except crtc.gc.ca, which still returns HTTP 403 to automated fetches (curl and WebFetch), so the text of CRTC 2026-43 and 2026-155 could not be read. Search results (titles and snippets only) are used for those two and are marked as such. No site file was edited.
